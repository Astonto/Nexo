# Nexo 1.7.0

Nexo now works in English as well as Spanish. Choose your language in **Settings → General**, save your preferences, then quit and reopen Nexo.

- Translated all sections, dialogs, tooltips, status messages and errors.
- New installations start in English. Existing Spanish preferences are kept.
- Macro names, categories, recorded input and user-entered text stay as you wrote them.
- The README, build instructions and release notes are now in English.
- Nexo's own code is available under the MIT license. Dependency notices are included.

## Downloads

Requires 64-bit Windows 10 or 11.

- **Nexo-1.7.0-windows-x64-portable.zip:** extract it and open Nexo.exe. Includes documentation and licenses.
- **Nexo-1.7.0-windows-x64.exe:** standalone executable; no installer or Python required.
- **SHA256SUMS.txt:** SHA-256 checksums for both downloads.

There is no 32-bit build because the current PySide6 release does not provide official Windows x86 packages.

To update, quit Nexo from Settings or the tray, then replace the executable. Keep your **Nexo-data** folder.
