# Nexo 1.6.18

Primera versión subida al repositorio. Incluye el grabador, el editor de macros y el autoclicker.

- El autoclicker acepta intervalos desde 1 ms y permite ignorar modificadores en su activador.
- Las macros pueden usar una ventana de destino y traerla al frente cuando sea necesario.
- Los temas claro y oscuro comparten el color de acento que elijas.
- Nexo se puede ocultar en la bandeja y solo mantiene una instancia abierta.

## Descargas

- **windows-x64-portable.zip:** descomprime y abre Nexo.exe.
- **windows-x64.exe:** el mismo ejecutable, sin comprimir. No es un instalador.
- **SHA256SUMS.txt:** sumas para comprobar los archivos.

Windows 10 u 11 de 64 bits. No hay una compilación x86 de 32 bits porque PySide6 no ofrece ese paquete para Windows.

Para actualizar, cierra Nexo y conserva la carpeta Nexo-data. Los archivos descargables no incluyen macros ni ajustes personales.
