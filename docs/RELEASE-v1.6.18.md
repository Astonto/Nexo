# Nexo 1.6.18

The first release uploaded to this repository. Includes the recorder, macro editor and autoclicker.

- The autoclicker supports intervals starting at 1 ms and optional modifier exclusions for its hold trigger.
- Macros can target a specific window and bring it to the front when needed.
- Light and dark themes use your chosen accent color.
- Nexo can hide in the system tray and keeps a single instance running.

## Downloads

- **windows-x64-portable.zip:** extract it and open Nexo.exe.
- **windows-x64.exe:** the same executable, uncompressed. It is not an installer.
- **SHA256SUMS.txt:** checksums for verifying the files.

Requires 64-bit Windows 10 or 11. There is no 32-bit x86 build because PySide6 does not provide that package for Windows.

To update, quit Nexo and keep the Nexo-data folder. Downloads do not contain personal macros or settings.
