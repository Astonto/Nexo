# Nexo 1.7.1

Nexo now has a Windows installer alongside the portable downloads.

- Installs for the current user by default, with an option to install for all users.
- Adds a Start menu shortcut and an optional desktop shortcut.
- Appears in Windows Apps with an uninstaller.
- The installed edition saves macros and preferences in `%LOCALAPPDATA%\Nexo`. Uninstalling keeps your data.
- Setup and uninstall ask you to quit a running copy before changing its files.
- The installer is available in English and Spanish. Both app languages remain available.

## Downloads

Requires 64-bit Windows 10 or 11.

- **Nexo-1.7.1-windows-x64-setup.exe:** Windows installer.
- **Nexo-1.7.1-windows-x64-portable.zip:** extract and run; no installation.
- **Nexo-1.7.1-windows-x64.exe:** standalone portable application.
- **SHA256SUMS.txt:** checksums for the downloads.

Quit Nexo from its tray icon or Settings before updating. Installing does not move an existing portable `Nexo-data` folder. To reuse its macros, choose its `macros` subfolder in **Settings → General → Macro folder**, or import them from the Library.
